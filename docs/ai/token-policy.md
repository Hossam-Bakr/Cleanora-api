# Token Policy

- Start with three to six files selected by `context-router.md`.
- Prefer headings, targeted searches, diffs, and relevant line ranges over whole-file loading.
- Summarize loaded context in at most five bullets.
- Do not reproduce full product documents, plans, diffs, or logs in responses.
- Load one skill by default.
- Keep each prompt scoped to one active phase, review, migration, or defect.
- Use references and links instead of duplicating rules.
- Read future phase material only when planning that phase or resolving a documented dependency.
- Treat missing context as a named gap, not permission to broaden the search indefinitely.
