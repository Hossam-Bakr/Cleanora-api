# Prepare Current Phase

1. Read the default router context.
2. Confirm the product documents are repository-local and identify the current phase.
3. Read only that roadmap section, relevant decisions, and blocking open questions.
4. Use `phase-planner`.
5. Create or align the phase `spec.md`, `plan.md`, `tasks.md`, and checklists.
6. Define in/out scope, dependencies, module ownership, authorization, audit, data changes, migration name, test scenarios, and DoD.
7. Stop on unresolved behavior that changes implementation.
8. Report the focused implementation prompt; do not implement unless requested.
