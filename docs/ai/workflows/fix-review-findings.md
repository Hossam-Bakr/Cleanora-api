# Fix Review Findings

1. Read the active artifacts, review report, and affected code.
2. Reproduce or verify every blocker and major finding before changing code.
3. Classify each finding as accepted, rejected with evidence, already resolved, or needs owner decision.
4. Make the smallest correct fix for accepted findings.
5. Add regression coverage.
6. Run focused tests, then broader quality gates proportional to risk.
7. Record outcomes in `review-resolution.md` using the template.
8. Do not expand scope, commit, or push.
