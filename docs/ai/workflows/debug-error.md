# Debug Current Error

1. Capture the exact command, error, environment, and expected behavior.
2. Reproduce with the narrowest deterministic case.
3. Identify the owning module and recent relevant diff.
4. Trace inputs, state, and side effects; test hypotheses rather than guessing.
5. State the root cause with evidence.
6. If repair is requested, make the smallest safe fix and add a regression test.
7. Run focused validation and record results using the bug-report template.
8. Do not hide unresolved symptoms with broad retries, casts, or disabled checks.
