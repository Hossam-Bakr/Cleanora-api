# Phase Documentation

Spec Kit phase artifacts live under:

```text
specs/<release-phase-id>-<phase-name>/
```

The canonical live pointer will be `docs/product/current.md` after the approved product pack is imported. Only the pointed phase may be active.

Use `docs/ai/workflows/prepare-phase.md` to create phase artifacts. Do not create future phase folders speculatively.

## Release navigation

- [Release 1 phase registry](release-1/README.md)

The registry lists approved roadmap phases for navigation. It does not activate
future phases or replace active Spec Kit artifacts.
