# Release Constraints

## Release 1

No maps, coordinates/radius matching, WebSockets, live offers, tracking, marketers, premium, Docker, or cloud deployment.

## Release 2

Adds marketers and premium. Maps, WebSockets, tracking, Docker, and cloud deployment remain excluded.

## Release 3

May add maps, realtime, tracking, Docker, and cloud planning only after explicit approval.

All releases prohibit internal stored-value user wallets. External payment/payout methods and recorded dues/settlements are distinct.
